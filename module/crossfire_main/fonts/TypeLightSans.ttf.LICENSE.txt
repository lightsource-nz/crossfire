This font is used purely as a small, license-clear binary fixture for
exercising 'crush font add' and 'crush render new' in automated tests. No
rights are reserved; it may be used, copied, or redistributed for any
purpose.

Replaced AVA.ttf (same repo/author/license) as the test fixture because
AVA's lowercase glyph outlines are visually identical/near-identical to
their uppercase counterparts (a real property of that font, not a bug in
crush's rendering pipeline -- verified by comparing against Arial), which
made it a poor fixture for a test meant to exercise real character
rendering. Type Light Sans has genuinely distinct upper/lowercase forms.
